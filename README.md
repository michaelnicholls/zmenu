# zmenu
Simple menu on transaction codes

Create/check service binding ZMN_MENU from ZMN_MENU

If it doesn't exist, https://michaelnicholls.github.io/simpleFiori/makeZip.html to create a BSP app

Use /ui2/flpam to create a new catalog which points to your BSP app and component

Create a PFCG role that accesses the catalog, and assign to some users
